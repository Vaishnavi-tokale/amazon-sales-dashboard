# 📊 Amazon Sales Dashboard

An interactive **Amazon Sales Dashboard built using Microsoft Excel** for sales and business performance analysis.

This project transforms raw Amazon sales data into an interactive business intelligence dashboard using **PivotTables, PivotCharts, KPIs, data analysis, and visualization techniques**.

---

## 📌 Project Overview

The Amazon Sales Dashboard provides a consolidated view of sales performance and helps analyze important business metrics such as revenue, orders, customers, products, categories, order status, payment methods, and geographic sales performance.

The dashboard is designed to help users quickly understand business performance and identify important trends from the underlying sales data.

---

## 🎯 Project Objectives

- Analyze overall sales performance
- Monitor revenue and order volume

- Analyze sales across product categories
- Understand monthly sales trends

## 📂 Dataset

The dataset contains approximately **39,966 sales/order records**.

### Key Fields

| Field | Description |
|---|---|
| OrderID | Unique order identifier |
| OrderDate | Date on which the order was placed |
| CustomerID | Unique customer identifier |
| CustomerName | Customer name |
| ProductID | Unique product identifier |
| ProductName | Name of the product |
| Category | Product category |
| Brand | Product brand |
| Quantity | Quantity purchased |
| UnitPrice | Price per unit |
| Total Price | Total product price |
| Discount | Discount applied to the order |
| Tax | Tax amount |
| ShippingCost | Shipping cost |
| Total Amount | Final order amount |
| PaymentMethod | Payment method used |
| OrderStatus | Current order status |
| City | Customer city |
| State | Customer state |
| Country | Customer country |
| SellerID | Seller identifier |

## 📈 Dashboard Visualizations

### 1. Monthly Sales Trends

Shows sales performance across different months and years to identify changes and trends over time.

### 2. Sales Analysis

Analyzes sales performance across different dimensions and helps compare business performance.

### 3. Top Products

Highlights products generating significant sales and helps identify high-performing products.

### 4. Order Status Analysis

Shows the distribution of orders across different statuses, including:

- Delivered
- Shipped
- Pending
- Cancelled
- Returned

### 5. Sales by Category

Compares sales performance across different product categories such as:

- Books

- Sports & Outdoors

### 6. Sales by Country
